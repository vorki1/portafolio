# Portfolio Web | Javier Saldaño

Sitio web personal y portafolio interactivo desarrollado para exhibir proyectos de software, experiencia profesional, arquitectura de datos y soluciones tecnológicas.

🔗 **Demo en vivo:** [vorki1.github.io/portafolio](https://vorki1.github.io/portafolio/#/)

---

## 🚀 Tecnologías Utilizadas

- **Frontend:** Vue 3 / React (según corresponda a tu implementación)
- **Lenguaje:** TypeScript / JavaScript
- **Estilos & UI:** CSS3 moderno, Tailwind CSS / Vuetify
- **Despliegue & Hosting:** GitHub Pages
- **Control de Versiones:** Git & GitHub

---

## ✨ Características Principales

- **Diseño Responsivo:** Adaptado completamente a dispositivos móviles, tablets y escritorio.
- **Secciones Modulares:** Presentación profesional, stack tecnológico, proyectos destacados y enlaces directos a código fuente y demos.
- **Rendimiento & Accesibilidad:** Carga ágil de componentes y contrastes visuales balanceados.
